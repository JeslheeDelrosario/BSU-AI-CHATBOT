   → Check spelling of first and last name
   → Verify faculty exists in Faculty table
   → Use Prisma Studio to confirm

   → Use 24-hour format: 08:00, 13:30
   → Not: 8:00 AM, 1:30 PM

Teaching schedule not showing in AI response
   → Verify code changes were applied
   → Restart the server
